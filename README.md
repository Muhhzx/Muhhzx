## ⭐ Featured Project

### [Job Analyzer](https://github.com/Muhhzx)
A full-stack TypeScript app that collects tech job listings from several public APIs, scores each one against the user's profile and uses AI (Anthropic Claude) to analyse selected jobs, including fit, gaps and salary estimates.

- ⚛️ **Frontend:** React / Next.js, TypeScript, Tailwind CSS
- ⚙️ **Backend:** Node.js / Fastify, Zod validation, SQLite
- 🔒 **Multi-user:** sessions with hashed passwords, login rate limiting, per-user locks
- ⚡ **Performance:** cut page loads from ~1–2 s to ~25 ms through profiling, caching and indexing
